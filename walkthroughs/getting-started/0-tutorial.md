## Welcome to Git Extended

Git Extended **supercharges** Git inside VS Code and unlocks the **untapped knowledge** within each repository.

Whether you’re a seasoned Git user or just getting started, Git Extended makes it easier, safer, and faster to leverage the full power of Git directly inside your editor.

### Key Capabilities
- **Current Line Blame & Authorship CodeLens**: Instantly see who modified any line or block of code.
- **Native Worktrees**: Seamlessly switch between worktrees and branches without disrupting work.
- **Revision Navigation**: Step through commit history and compare diffs effortlessly.
- **Rich Side Bar Views**: Commits, File History, Branches, Stashes, Tags, and Search & Compare.
- **Zero Telemetry & Subscriptions**: 100% offline, privacy-first, and completely free.
