Git Extended

Git supercharged

Git Extended supercharges Git inside VS Code. It helps you to visualize code authorship at a glance via Git blame annotations and CodeLens, seamlessly navigate and explore Git repositories, manage Worktrees effortlessly, compare revisions, and so much more.

Quick Setup

Git Extended is powerful, feature rich, and highly customizable to meet your needs. Do you find CodeLens intrusive or the current line blame annotation distracting — no problem, quickly turn them off or change how they behave using the options below.

For more options, use the interactive Git Extended settings editor
